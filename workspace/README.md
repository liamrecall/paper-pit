# workspace

The seats talk through files, so a session can be replayed and argued with later.
A run fills these folders:

```
workspace/ideas/day-N.jsonl      every setup TAPE flagged, with WIRE's funding tag
workspace/tickets/day-N.jsonl    the ones that survived DEVIL and SIZER
workspace/journal/day-N.jsonl    every verdict: killed, dropped, blocked, filled, closed
workspace/journal/day-N.md       the session report
```

Run output is not committed - only this note is.
